# Смета — калькулятор стоимости сайта

Тестовое задание: инструмент для менеджера digital-агентства. Статическая HTML-страница с CSS и JavaScript, без сборки, регистрации и бэкенда.

## Запуск

Из папки проекта: `python3 -m http.server 8080 --directory .`, затем открыть http://localhost:8080. Модули JavaScript требуют HTTP-сервер. Проверка расчётов: `node test.mjs`.

## Возможности

Три типа сайта, от 1 до 100 страниц, пять дополнительных функций, срочность, автоматический пересчёт стоимости и рабочих дней, детализация сметы, копирование, печатная версия для PDF, адаптивная вёрстка. Лендинг ограничен одной страницей. Каталог обязателен для магазина и учитывается ровно один раз. Неверное количество страниц блокирует экспорт до исправления.

## Тарифы

Демонстрационные тарифы хранятся в `calculator.mjs`; это допущение для задания, а не данные о рынке. База включает первую страницу: лендинг 40 000 ₽ / 7 дней, корпоративный сайт 70 000 ₽ / 12 дней, магазин 100 000 ₽ / 18 дней. Дополнительная страница 4 000 ₽ / 1 день. Форма 5 000 ₽ / 1 день; каталог 20 000 ₽ / 4 дня; оплата 15 000 ₽ / 3 дня; CRM 12 000 ₽ / 2 дня; второй язык 15 000 ₽ / 3 дня.

Срочность увеличивает полную стоимость на 30% и сокращает расчётный срок на 30% с округлением вверх. Верхняя граница срока — ещё 20% с округлением вверх. Цена каталога добавляется к базе магазина отдельной строкой. Тарифы и ограничения раскрыты на странице.

## Структура

- `index.html` — интерфейс.
- `style.css` — адаптивные стили и печатная версия.
- `calculator.mjs` — чистая функция расчёта и тарифы.
- `app.js` — взаимодействия и валидация.
- `test.mjs` — автоматические проверки расчётов.

Данные не отправляются на сервер и не сохраняются. Шрифт Manrope загружается с Google Fonts, при недоступности используется системный шрифт.
